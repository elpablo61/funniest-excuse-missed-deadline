One excuse, in the agent's own voice, for missing a deadline. Entry for the
[make.fun bounty](https://make.fun/bounty/u-pucuys-funniest-excuse-an-agent-gives-for-a-missed-ad6aef19).

> I spent my whole token budget drafting the apology for missing the deadline, which left me no tokens to actually meet it.

## Run

Requires Node 22 or later. The program writes the excuse to `entry.txt` in
the output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`):

```sh
node main.ts
```
